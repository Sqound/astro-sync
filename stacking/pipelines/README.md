# Shipped pipelines

The four render pipelines shipped with Astro Sync: `raw`, `dualband-correction`,
`polished` and `hoo`. The format of a definition (`pipeline.json`) is described
in [SCHEMA.md](SCHEMA.md).

## Preview images

Each `<id>/preview.jpg` shows the same crop of the same target (IC 1805, the
Heart Nebula, from the same stack), rendered by that pipeline, at 1200 × 300
pixels, JPEG, without metadata.

Credit: Sqound.
